# 启动与首次调用测量

本文件记录本次重构的可复现实测，而不是通用性能承诺。测试在同一台机器、同一 Neovim 0.12.5、隔离的 XDG 数据/状态/缓存目录中执行三次；基线使用 `main` 的导出副本，并关闭其自动安装，以避免把网络和安装工作计入启动时间。

| 配置 | 场景 | 三次进程耗时（ms） |
| --- | --- | --- |
| main 基线 | 空启动 | 188.15、132.79、155.01 |
| main 基线 | 直接打开 Python 文件 | 334.71、188.75、176.36 |
| 模块化 minimal | 空启动 | 47.06、36.59、36.89 |
| 模块化 minimal | 直接打开 Python 文件 | 74.18、56.07、69.10 |

首次功能调用的单次细分测量：打开 Python 文件 4.70 ms，创建第一个终端 10.97 ms。它们仅表示本次受控运行的结果；插件版本、文件系统缓存、CPU 调度和项目大小都会改变数值。

重测命令：

```sh
TEST_RUNTIME=/private/tmp/nvim-modular-test python3 tests/benchmark.py
```

脚本把完整原始结果写入隔离运行时的 `benchmark-results.json`，不会修改仓库锁文件或用户的 Neovim 数据目录。
